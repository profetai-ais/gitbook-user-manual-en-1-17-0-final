# Personalization

## Introduction

Personalization lets an Agent remember key information and keep using it in later interactions, which makes conversations more coherent and task handling more efficient. When you provide preferences, background information, frequently used settings, project context or fixed formats during a conversation, the system can turn them into reusable memories that the Agent refers to automatically later on, so you do not have to repeat yourself or confirm the same details again.

For example, how you like to be addressed, tone and style, output format (bullet list, table or paragraphs), the products or projects you work on, process preferences, common decision principles, and standards that need to stay consistent over time can all be kept as memories and applied when relevant.

Memory is available on the **Personalization** tab, under your avatar in the upper right.

### Memory

Memory is split into **Save Memory** and **Reference Memory**.

<figure><img src="../.gitbook/assets/image (239).png" alt=""><figcaption></figcaption></figure>

* **Save Memory**: When enabled, Agents are allowed to save memories.
* **Reference Memory**: When enabled, Agents are allowed to cite memories from the memory store in their responses.

## Managing memories

Memory management is behind the **Manage** button, and is split into **Personal Memory** and **Agent Memory**.

<figure><img src="../.gitbook/assets/image (640).png" alt=""><figcaption></figcaption></figure>

### Personal Memory

When Reference Memory is enabled, the memories stored here can be used by all Agents. Personal Memory holds up to 50 memory entries.

> Note: When the limit is exceeded, the system automatically deletes the least frequently used entries.

<figure><img src="../.gitbook/assets/image (641).png" alt=""><figcaption></figcaption></figure>

### Agent Memory

When Reference Memory is enabled, an Agent can use the memories in its own memory store. Each Agent holds up to 50 memory entries.

> Note: When the limit is exceeded, the system automatically deletes the least frequently used entries.

## How to save a memory

<figure><img src="../.gitbook/assets/image (644).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (645).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (646).png" alt=""><figcaption></figcaption></figure>

1. Before using memory, make sure **Save Memory** is enabled.
2. In the conversation interface, select the Agent you want to talk to and enter the content you want it to remember.
3. Once the memory is saved, the Agent tells you that you can review it under **Personalization → Memory management**.
