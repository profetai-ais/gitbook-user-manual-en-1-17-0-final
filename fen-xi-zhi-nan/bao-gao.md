# Report

## Introduction

Report provides usage and operational analytics for AI Studio, which helps administrators track Tokens, Quota, task runs and feature usage on the platform. Visual dashboards show data on Sessions, Memory, Workflow, RAG, Speech and more, as a basis for cost analysis, usage tracking and operational management.

This page brings together reporting and data visualization tools, and you can see the Dashboards, Charts and Datasets your permissions allow.

## Dashboard

**Dashboard** brings the analytics dashboards you have created together in one place. Each Dashboard contains one or more charts for looking at the data on a particular topic.

Common Dashboard topics include:

* Agent usage
* Token usage and cost
* User activity
* Knowledge Base and Agent relationships
* Permissions and access
* Task runs and anomaly monitoring

The Dashboard list shows each dashboard's name, status, owner and last modified time. Click a Dashboard name to open it and see its charts.

## Chart

**Chart** is where you manage and create report charts. To create one, first select a dataset, then select a chart type.

Many chart types are supported, for example:

* Area Chart
* Bar Chart
* Big Number
* Line Chart
* Pie Chart
* Table
* Heatmap
* Pivot Table
* Scatter Plot
* Treemap

Different chart types suit different data. A Line Chart suits trends, a Pie Chart proportions, a Table detailed records, and a Big Number a key figure.

Creating charts is usually available to users with report management permissions. Other users can view existing charts and Dashboards according to their permissions.

## Dataset

**Dataset** shows the datasets available for building charts and Dashboards. A Dataset is the data source for reporting, and charts are generated from the columns and content of the Dataset you select.

The Dataset list shows each dataset's name, type, database, schema, owner and last modified time.

## Notes

Which Dashboards, Charts and Datasets you can see in Report depends on your permissions. If you cannot see a particular report or dataset, check whether you have the corresponding view or management permission.

This page is mainly for reviewing and analyzing data. To change a Dashboard, Chart or Dataset, confirm that you have report management permissions and configure it as needed.
