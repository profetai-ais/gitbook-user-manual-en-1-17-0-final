# AI Studio Roles and Permissions

## **Functional role types in AI Studio**

The system provides three built-in functional role types:

* **AI Studio Admin:** Can view every feature menu on the platform, and can grant other users advanced permissions for Knowledge Base and Agent features.
* **AI Studio Domain User:** Can view the Knowledge Base, Capability, Analytics, Template and Agent menus, and can build document knowledge bases and Agents for different domains and scenarios.
* **AI Studio User:** A general user within the company. Can only use published Agents in the Workspace.
