## Opening an Agent from a link

<figure><img src="../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

When other users open a shared Agent link, they go straight to the Workspace:

* The system first adds the Agent to the user's Workspace and then opens a conversation, so there is no need to look for it in Explore.
* The left-side navigation menu stays visible, so users can switch to other features.
* Refreshing the page does not add the same Agent again.

Opening a conversation link from a notification, a schedule record or an Agent's settings page also takes you to the Workspace with the left-side navigation menu visible. If you created the Agent yourself but have not published it yet, opening it from a link still loads your previous conversations.

## **Exploring Agents and adding them to your favorites**

<figure><img src="../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

1. Click **Workspace** in the menu on the left side of the page.
2. Hover over the Agent you want to use, or enter a keyword in the search field to find it.
3. Select the Agent and click **Add to My Favorites** on its card.
4. Click **Favorites** at the top of the page to switch to your personal area and check that the Agent has been added.
