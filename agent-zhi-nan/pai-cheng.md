# Schedule

## Introduction

<figure><img src="../.gitbook/assets/image (700).png" alt=""><figcaption></figcaption></figure>

The Schedule page in the Agent settings lists every schedule related to the current Agent. It is the same as the schedule management page, except that it is already filtered to this Agent, so you can view and manage its schedules while editing it instead of switching to the schedule management page to search.

## What you can do

* **View schedules**: browse this Agent's schedules and their status.
* **Create a schedule**: the process is the same as on the schedule management page, except that the Agent is fixed to the current one and cannot be changed. For the steps, see Creating a Schedule.
* **View logs**: open a schedule's detail page to see the record and result of each run. See Viewing Logs.

{% hint style="info" %}
For the full details of run modes, recurrence settings, run limits and notifications, see the [Schedule guide](../gong-zuo-zhi-nan/pai-cheng.md).
{% endhint %}
