  An Agent is a conversational application. You enter text (a prompt), and the
  Agent passes it to a large language model (LLM) through processing suited to
  your use case to get a response.
---

# Agent Overview

## **Key advantages**

<figure><img src="../.gitbook/assets/image (658).png" alt=""><figcaption></figcaption></figure>

* **Variety**: Several Agent types cover different needs, and a few simple settings are enough to build a high-quality Agent application.
* **Governance**: Agent permissions can be managed so that generative AI use stays within company policy.
* **Accuracy**: Answers draw on the information in your knowledge base, which reduces the risk of hallucination.
* **Flexibility**: Hybrid scenarios are supported, and developers can swap the LLM model or service at any time as requirements change.
