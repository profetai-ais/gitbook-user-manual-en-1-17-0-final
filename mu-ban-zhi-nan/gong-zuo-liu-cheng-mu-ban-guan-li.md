# Workflow Template

## Introduction

Workflow templates are used by Workflow Agents. They let you design visually how the prompts a user enters in a conversation with a Workflow Agent are handled.

> **Note**: By default, only AI Studio Admins can change these settings.

## **Creating a new workflow template**

> For how to edit a workflow, see [Workflow](../agent-zhi-nan/bian-ji-gong-zuo-liu-cheng.md).

## **Creating a new template**

![](<../.gitbook/assets/01-create-entry-full (1).png>)

![](<../.gitbook/assets/02-create-workflow-template-full (1).png>)

1. Click the **Add** button in the upper right and select **Template**.
2. Enter a name in the **Name** field, then click the button on the right to add multilingual labels. See [Multilingual settings](gong-zuo-liu-cheng-mu-ban-guan-li.md#duo-guo-yu-yan-she-ding).
3. Enter a description in the **Description** field, then click the button on the right to add multilingual labels. See [Multilingual settings](gong-zuo-liu-cheng-mu-ban-guan-li.md#duo-guo-yu-yan-she-ding).
4. Click **OK** to finish. The new workflow appears in the template list, and clicking its name opens the editor.

#### Multilingual settings <a href="#duo-guo-yu-yan-she-ding" id="duo-guo-yu-yan-she-ding"></a>

![](<../.gitbook/assets/03-language-settings-full (1).png>)

1. Click the globe button to translate automatically. You can also edit the content manually.
2. When the automatic translation is done, click **OK** to save.

> Note: The large language models available in the **Model** menu depend on the configuration of your installed environment. The options shown in this manual are for reference only.

## **Importing a template**

![](<../.gitbook/assets/04-import-entry-full (1).png>)

![](<../.gitbook/assets/05-import-template-full (1).png>)

This option imports a workflow template from a file into a new workflow for editing.

1. Click the More button in the upper right and select **Import file**.
2. Click the **file upload area** and select the template file to import (a `.pwflow` file).
3. Enter a name in the **Name** field, then click the button on the right to add multilingual labels. See [Multilingual settings](gong-zuo-liu-cheng-mu-ban-guan-li.md#duo-guo-yu-yan-she-ding).
4. Enter a description in the **Description** field, then click the button on the right to add multilingual labels. See [Multilingual settings](gong-zuo-liu-cheng-mu-ban-guan-li.md#duo-guo-yu-yan-she-ding).
5. Click **OK** again to finish. The new workflow appears in the template list.
