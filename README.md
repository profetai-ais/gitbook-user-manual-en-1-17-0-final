## **Core features and technical highlights**

* **Knowledge Base**: Build a document knowledge base in three simple steps. This addresses the limited built-in knowledge and unreliable answers of large language models, and lets you authorize domain experts to manage and maintain their own knowledge bases securely, without exposing critical knowledge.
* **Agent**: Create Agents quickly for different use cases, and grant permissions so users can start using them right away.
* **Prompt applications / Template management**: Turn frequently used prompts into reusable apps, so users only need to supply the key information to get more accurate answers instead of typing long prompts themselves.
* **AI Workflow**: A flexible AI workflow mechanism that supports different RAG scenarios and integrates external search, improving RAG design efficiency and expanding what AI Studio can do.
